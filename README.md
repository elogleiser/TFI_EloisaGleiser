Los niveles acordes a la entrega, L_Quests_Blueprints y L_Quests_CPP se encuentran en la carpeta Maps.

Para L_Quest_CPP la quest se entrega al hacer overlap y el menú se puede desplegar con la letra J.

Para L_Quests_Blueprints la quest se activa al presionar la letra E al lado del QuestGiver y para disparar usar click izquierdo.
